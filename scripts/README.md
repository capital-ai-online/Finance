# CAPITAL-AI Scripts

## Deutsch
`scripts/` enthält ausschließlich ausführbare Repository-, CI-, Security-, Deployment- und Automationswerkzeuge. Leere Kategorien werden nicht durch `.gitkeep` künstlich vorgehalten.

Aktive Bereiche:
- `automation/` — Repository-, Release-, Traceability-, Vocabulary- und Build-Automation;
- `deployment/` — Deployment-bezogene Hilfswerkzeuge;
- `pr/` — Pull-Request-Governance und Tests;
- `security/` — Security-, Hardening- und Produktionsinvarianten.

Regel: Ein Script wird nur entfernt, wenn Aufrufer, CI-/package-Verwendung und fachliche Authority geprüft wurden. Ein leerer historischer Kategoriename begründet keinen dauerhaften Placeholder.

## English
`scripts/` contains executable repository, CI, security, deployment and automation tooling only. Empty categories are not retained through placeholder `.gitkeep` files. Executable scripts may be removed only after caller, CI/package usage and governance authority have been checked.
