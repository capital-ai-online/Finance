# Security Policy

## Supported Versions

Security fixes are maintained for the current `main` branch and the current `0.6.x` release line.

| Version | Supported |
| --- | --- |
| `main` / `0.6.x` | Yes |
| `< 0.6.0` | No, unless explicitly covered by a remediation or security notice |

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities, credentials, tokens, personal data, exploit details, or other security-sensitive evidence in public issues or pull requests.

For this private repository, report vulnerabilities through an authorized private channel to the repository or organization owner. Repository administrators should use the repository's private security workflow when available. Include the affected component, commit or version, security impact, reproduction steps, relevant evidence, and any known workaround or mitigation.

Security findings remain subject to the repository's current Security, Governance, Human/CODEOWNER merge, and protected-mutation controls. This file does not create a separate security authority or response-time SLA.
