# Archived Documentation

## Deutsch
Dieser Bereich enthält historische CAPITAL-AI-Dokumente, deren Evidence-Wert erhalten bleibt, die jedoch keine aktuelle Architektur-, Governance-, Security-, Compliance- oder API-Authority darstellen.

Kategorien:
- `raw-materials/`: ältere Raw-Materials-Agent-, Scoring-, Orchestrator- und API-Snapshots;
- `legacy/`: überholte Blueprint-, Architektur-, Deployment- und Integrationsdokumente;
- `evidence/`: historische Security-/Compliance-Audit-Snapshots;
- `evidence/post-pvc-folder-mapping/`: nach der PVC–Projektordner-Verbindung entstandene Evidence- und Work-Claim-Overlay-Dateien — archiviert und deaktiviert am 2026-09-02.

Aktuelle organisatorische Verbindung bleibt nur:
- `docs/projects/README.md`
- `docs/projects/PROJECT_VALUE_CHAIN.md`

Aktuelle technische Entscheidungen müssen gegen ESS, ADRs, aktuelle `docs/architecture/`-Dokumente, Registries, Tests und Production Evidence geprüft werden.

## English
This directory preserves historical CAPITAL-AI documentation for evidence and traceability only. Files under `docs/archive/` are non-canonical and must not override current ESS contracts, ADRs, architecture specifications, registries, tests or production evidence.

The post-PVC folder-mapping overlay is archived under `evidence/post-pvc-folder-mapping/`.
