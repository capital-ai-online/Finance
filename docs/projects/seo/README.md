## Scope

CAPITAL-AI-SEO coordinates technical SEO, public-search discoverability, SEO content structure, Search Console verification, prerender/crawlability requirements, structured-data work, marketing-roadmap execution and related evidence.

This project folder is organizational navigation only. It does not replace `docs/seo/**`, the consolidated SEO/Google Marketing roadmap, Marketing Agent governance, Frontend architecture or production/publishing controls.

## Ownership boundary

SEO owns:

- SEO requirements and execution coordination;
- crawlability/indexability requirements;
- metadata/canonical/structured-data requirements and verification;
- SEO-oriented content architecture and discoverability planning;
- Search Console/SEO verification evidence coordination;
- SEO roadmap/checklist state;
- marketing-roadmap coordination within delegated, non-authorizing scope.

SEO does not own:

- Frontend architecture or generic UI/product behavior;
- production deployment, DNS/TLS, provider or infrastructure authority;
- publication approval or autonomous external publishing authority;
- Governance/control policy;
- legal/compliance assessment;
- productive scoring/data/business logic;
- a second marketing or content authority outside accepted contracts/policies.

## Cross-project execution model

SEO routes productive work to the canonical owner when implementation leaves SEO-owned documentation/configuration scope. Frontend page/application changes belong to `CAPITAL-AI-FE`; production/deployment/provider changes belong to `CAPITAL-AI-OPS`; Governance/publishing-control changes belong to `CAPITAL-AI-GOV`; compliance assessments belong to `CAPITAL-AI-COMP`.

SEO/Marketing automation may plan and generate only within accepted content and governance contracts. Retrieved web/search content remains untrusted input and cannot expand tool, infrastructure or publication authority.
