# CAPITAL-AI-OPS Evidence

Evidence under this project surface is non-authorizing and identity-bound.

Preferred order:

1. runtime/provider readback;
2. health/deployment identity;
3. negative/positive Security tests where applicable;
4. metrics/logs/traces/EventMesh reliability evidence;
5. hosted CI/release evidence;
6. code/configuration;
7. approved runbook;
8. roadmap/project status.

Security-related packages return evidence to CAPITAL-AI-SEC and remain `IMPLEMENTED` or `EVIDENCE_READY` until independent Security verification.
