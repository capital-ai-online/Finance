# Evidence — D3 Soft-404 Production Gap (2026-08-16)

**Roadmap:** SEO-GM-ROADMAP-0002 / WP-D3  
**Production commit probed:** `355c94b910336454d6de4494f9c2660b721925fc` (version `0.6.0`)  
**Probe time:** 2026-08-16T01:39Z (CEST)

## Finding

Code for Soft-404 existed on `main` (`installProductionSoft404Intercept` in `registerApplicationRoutes`, helpers in `server/runtime/spaFallback.ts`, unit tests green), but **production still returned HTTP 200 + SPA shell** for unknown paths.

| URL | Observed | Expected |
|-----|----------|----------|
| `https://capital-ai.online/not-a-real-page-xyz-seo-check` | **200** `text/html` (full `index.html`) | **404** plain `Not Found` |
| `https://capital-ai.online/impressum` | 301 → `/impressum/` | 200 without slash (Q2) |
| `https://capital-ai.online/impressum/` | 301 → `/impressum` | 200 (or single canonical) |

## Root cause analysis

1. **Catch-all still naive in composition root**  
   `server.application.ts` `startServer()` production branch still registered:
   ```ts
   app.use(express.static(distPath));
   app.get('*', (req, res) => {
     res.sendFile(path.join(distPath, 'index.html'));
   });
   ```

2. **Prototype intercept is not trustworthy under the production bundle**  
   `installProductionSoft404Intercept()` patches `require('express').application.get`.  
   Production server is **esbuild-bundled** (`npm run build` → `dist/server.cjs`). ESM `import express` used to create `app` and CJS `require('express')` inside the intercept can resolve to **different module instances**, so the prototype patch never wraps the real `app.get('*')` handler.

3. **Q2 trailing-slash vs prerender directories**  
   S2 prerender writes `dist/impressum/index.html` (and agb/datenschutz).  
   Default `express.static` **redirects directories to a trailing slash**, while `registerTrailingSlashNormalize` strips trailing slashes → redirect ping-pong risk.

## Fix applied in this PR

1. Replace production catch-all with **`registerProductionSpaFallback(app, distPath)`** (explicit allow-list; unknown → 404).
2. Mount static as `express.static(distPath, { redirect: false, index: false })` so public HTML is owned by the SPA fallback and Q2 is not fought by directory redirects.
3. Keep unit/contract tests; update D3 status docs.
